# Test photos (not included)

The face-recognition tests (`tests/test_brain.py`) need two photos of **different people**, one face
each, clearly visible:

- `face_a.jpg`: person A (also shown by the robot test page's `?test=1&face=1` mode)
- `face_b.jpg`: person B

They aren't included in the repository. Use photos you're allowed to use: your own, with the people's
permission, or freely licensed ones (e.g. public-domain portraits). Without them those tests are skipped.
